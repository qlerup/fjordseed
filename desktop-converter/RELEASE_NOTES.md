Vælg Dolby Vision i FjordSeed: behold profil 8.1 i filmen, eller gem data separat og afspil HDR10 indtil senere gendannelse. Samme indstilling bruges på pc og server. Nye jobs gemmer valget; eksisterende jobs ændres ikke. Original opløsning og lydspor bevares.
